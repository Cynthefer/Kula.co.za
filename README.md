# KULA AUTO ELECTRICAL ENGINEERING

Company profile website for Kula Auto Electrical Engineering Pty (Ltd) — specialists in heavy-duty auto electrical service and repair for earth-moving and mining equipment.

## Stack

- Django 5.x
- Supabase (PostgreSQL)
- Cloudinary (media storage)
- Tailwind CSS (CDN)
- Alpine.js, HTMX, SortableJS, Swiper, AOS, Notyf, Lucide
